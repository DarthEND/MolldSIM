# 🌐 MolldSIM

**MolldSIM** este un website colorat și prietenos unde poți găsi abonamente de **telefonie mobilă**, **internet** și **internet + televiziune** de la toți furnizorii principali din Republica Moldova.  
Scopul proiectului este de a ajuta utilizatorii să compare ușor ofertele și să găsească planul care **li se potrivește cel mai bine**.

---

## 🚀 Funcționalități
- ✅ Pagini pentru **telefonie mobilă**, **internet**, **internet + TV**
- 🔄 **Tab-uri interactive** pentru fiecare operator
- 📊 **Carduri** cu detalii despre prețuri, viteză, minute și canale TV
- ❓ Secțiune de **Întrebări frecvente (FAQ)**
- 💡 Design **responsive**, inspirat de Moldcell și Orange

---

## 🧠 Tehnologii utilizate
- **HTML5 / CSS3**
- **JavaScript** pentru taburi interactive
- *(Versiunea anterioară folosea React + Tailwind)*
